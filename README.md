# MultiDesk-LLP — Downloads

Este repositório público contém somente instaladores Windows e arquivos de atualização do MultiDesk-LLP. O repositório do código-fonte do aplicativo permanece privado.

As versões validadas são publicadas em [Releases](https://github.com/LucasLPDev/MultiDesk-LLP-Downloads/releases). Para a primeira instalação, execute o arquivo **MultiDesk-LLP-Setup-<versão>.exe** da versão mais recente.

Depois de instalado, abra **Atualizações → Atualizar agora** no aplicativo e, ao terminar o download, escolha **Reiniciar e concluir**. Perfis, logins e plugins permanecem no diretório de dados da sua conta Windows.

O Setup instala para o usuário atual e cria os atalhos. O instalador ainda não tem assinatura digital. Os arquivos `latest.yml`, `.blockmap` e `SHA256SUMS.txt` acompanham o instalador para distribuição e verificação; não precisam ser selecionados manualmente no aplicativo.

A opção Code → Download ZIP deste repositório não instala o aplicativo. Use o Setup publicado em Releases.
