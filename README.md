# MultiDesk-LLP — Downloads

Este repositório público contém instaladores Windows, arquivos de atualização e pacotes de temas opcionais do MultiDesk-LLP. O código-fonte do aplicativo permanece privado.

A **0.9.0 está disponível**, com várias áreas de trabalho, presets e correções do /hunt, seleção da grade e nomes dos alertas. Clique no **nome da área ▾** no cabeçalho para criar janelas e salvar/abrir presets. A sinalização de indisponibilidade do leitor no Ultra Economia foi corrigida; **o acompanhamento contínuo dos níveis no Ultra ainda não está disponível**.

As versões validadas são publicadas em [Releases](https://github.com/LucasLPDev/MultiDesk-LLP-Downloads/releases). Para a primeira instalação, execute o **MultiDesk-LLP-Setup-<versão>.exe** da versão mais recente.

Depois de instalado, abra **Atualizações → Verificar versão → Atualizar agora** e, ao terminar o download, escolha **Reiniciar e concluir**. A atualização usa a mesma pasta e preserva perfis, logins, plugins e presets no diretório de dados da sua conta Windows.

A partir da **0.7.0**, o **Essencial** vem integrado como tema padrão. Em **Preferências → Aparência → Temas**, consulte o catálogo e escolha **Recorte → Baixar e ativar** para instalar o tema opcional. Temas instalados funcionam offline; você pode voltar ao Essencial pelo painel ou menu Aparência. Atualizações de temas exigem comando e não recarregam as páginas das contas.

O catálogo e os pacotes de dados ficam em `themes/v1/`, separados das releases e de `latest.yml`. Não são plugins de automação e não contêm código executável.

O Setup instala para o usuário atual e cria os atalhos. O instalador ainda não tem assinatura digital. Os arquivos `latest.yml`, `.blockmap` e `SHA256SUMS.txt` acompanham o instalador para distribuição e verificação; não precisam ser selecionados manualmente no aplicativo.

A opção Code → Download ZIP deste repositório não instala o aplicativo. Use o Setup publicado em Releases.
